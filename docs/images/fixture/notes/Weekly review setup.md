# Weekly review setup

I keep my capture settings in this note. The block below shows how Quick Capture differs from what I want, and applies the difference after a review.

```settings-profile
{
  "version": 1,
  "plugins": {
    "quick-capture": {
      "captureFolder": "Inbox",
      "autoSaveSeconds": 30,
      "openAfterCapture": false,
      "showRibbonIcon": true,
      "timestampFormat": "YYYY-MM-DD HH:mm",
      "apiKey": "sk-demo-0000"
    }
  },
  "notes": {
    "plugins.quick-capture.captureFolder": "One place to sort from at the end of the week.",
    "plugins.quick-capture.autoSaveSeconds": "Half a minute is enough."
  }
}
```
