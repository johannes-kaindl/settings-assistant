# Settings Assistant — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something, getting something done, looking something up and understanding why are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started: First profile](tutorial-first-profile.md) — from the install to your first applied change, and how to take it back.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started: First profile](tutorial-first-profile.md)** | Learning-oriented. Write a profile in a note, read the check rows, apply one change and undo it. |
| **[Align two vaults](howto-align-two-vaults.md)** | Task-oriented. Carry settings from one vault to another with a profile note. |
| **[Ask the chat](howto-ask-the-chat.md)** | Task-oriented. Let a local model draft a profile, read what it was sent, apply or save the result. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "No chat model is set up yet", "Profile is not valid JSON", "Another apply run is still in progress". |
| **[Profile format](reference-profile-format.md)** | Reference. Every section, the version rule, notes, unknown sections. |
| **[Check rows](reference-check-rows.md)** | Reference. Every row status with its exact text, and the outcomes after an apply. |
| **[Known limits](reference-known-limits.md)** | Reference. What version 1 does not do, and the small quirks that are known. |
| **[Plugin API v1 (German)](API.md)** | Reference, for plugin authors; the page is in German. Redacted reading, plan, apply, tool definitions. |
